# Sql-Python-Connect

## 📊 Project Overview
1. SQL queries to extract top products by revenue and quantity
2. Visualizations using Python (Seaborn/Matplotlib)
3. Automated database connection with SQLAlchemy

## 🛠️ Technical Implementation
- **Database**: MySQL (`sales_db` with `salesdata` table)
- **Tools**: 
  - Python (Pandas, SQLAlchemy, Seaborn/Matplotlib)
  - Jupyter Notebook
- **Key Features**:
  - Top 5 Most Profitable Products (Revenue)
  - Top 5 Most Bought Products (Quantity)
  - Warning-free optimized code
